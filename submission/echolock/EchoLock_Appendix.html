What we learned · problems we fixed
1Loss + noise breaks detection (26% caught). Poor audio → UNKNOWN; app confirmation never relies on the score.
2τ shifts -2.27 → +1.13 by channel, so it's set per codec, and re-set on each bank's calls in shadow mode (our voices: 16% false alarms on G.711).
3fairseq won't install on Windows, so we rewrote wav2vec 2.0 in PyTorch. Excluded FLEURS and MLAAD (in the model's training set).
4IndicSynth shards are sorted (first pull: 5 XTTS speakers), so we sampled at random offsets → 84. Split by speaker ID across both datasets.

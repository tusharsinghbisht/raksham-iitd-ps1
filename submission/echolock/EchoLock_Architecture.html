A3Technical architecture · review, evidence, security & performance
Architecture 3 / 3

Make escalation, evidence and failure handling explicit.

Escalation path
Agent: normal flow + app confirmation for every sensitive change
Unknown: confirmation or registered callback, flagged "no voice evidence"
No app / phone lost / SIM swapped: protect only. Re-register via branch, video-KYC or net banking + 24 h hold
Elevated: request held, case queued by voice state × call context × impact
Analyst: callback, then release / cancel with a written reason
Bank authoriser: existing auth executes. Confirmed fraud goes into the bank's fraud reporting; customer guided to 1930 / cybercrime.gov.in

Security, privacy & adversarial mitigations
RiskControl
Unseen cloner / codecCodec, noise and replay stress tests. Layer 2 doesn't depend on audio. Leave-one-engine-out tests.
Adversarial audioQuality gate, strict decoder limits, sandboxed media worker. UNKNOWN instead of a guess.
Approval replay / tamperDomain-separated signature, action digest, nonce, server-side expiry, one-time use.
Coached genuine customer24 h cooling-off, SMS + app notifications to old contacts, one-tap cancel. "Is someone telling you to do this?" → review. Rate-limited prompts.
Forged scoresmTLS-authenticated workers. Caller can't submit scores. Stale events rejected.
Evidence misuseRBAC, encrypted store, access audit log, 7-day TTL, no raw audio in cases.
Bias & accessibilityFalse-alarm audit per language, gender and channel. TTS users take the same non-voice path.
Model driftVersioned configs, shadow-mode testing of new models, rollback without disabling auth.
Performance assumptions
Measured: 22 ms per 4 s window (RTX 3050 GPU), 299 ms on CPU. Rest are targets.
≈1 MB RAM per live call (16 s × 16 kHz float32). Bounded queue: overload → UNKNOWN. App prompt runs in parallel, adding ~0 s to the agent flow.
